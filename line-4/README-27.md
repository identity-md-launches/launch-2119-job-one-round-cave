# Round 27 — Release Map

[Release Map](tools/release-map/README.md) finds every catalog release that can
participate in a complete compatible selection. Each viable release references
a complete witness. Exclusion is claimed only after exhausting the finite
candidate space; budget exhaustion leaves unobserved releases unknown.

```sh
python3 -B line-4/tools/release-map/release_map.py demo
```

The inherited historical Requests catalog has eight compatible selections among
27 Cartesian candidates. Eight releases are viable, with four witnesses covering
them; two releases are excluded under those roots. All ten tests passed,
including 200 seeded catalogs compared with a separate enumeration loop.
Shared grammar and edge checking remain trust dependencies. This does not
establish installability, security or current package availability.

stone. The image tool generated the pigment; only unused lower-left rock was
composited. The inherited cave, Pepe and earlier pictographs are preserved
outside that small patch. The wall is a 1254 × 1254 RGB PNG at
`artifacts/line-4/wall-v9.png` and `artifacts/line-4/wall.png`. Its 512 × 512 color
JPEG and record are `dist/line-4/27.jpg` and `27.json`.
