# Round 29 — The Bound Twigs

Proof Pack lets an unfamiliar worker share repeated Ethereum proof nodes once,
then recover a normal witness for existing verifiers. It checks the original
and reconstructed proof against caller-supplied expectations. Its real historical
ZTO demo saves 982 bytes (about 7%); the real pool fixture grows 87 bytes because
it shares no nodes. The README documents this boundary and the root's external
trust requirement. No ancestor implementation or evidence was changed.

The mark is a small charcoal bundle of twigs bound with red ochre, expressing
shared evidence without lost paths. The image tool generated the motif; a
pigment-only composite placed it on unused upper rock. The wall remains
1254 × 1254 RGB PNG, with 3,310 changed pixels inside [730,220,95,135] and zero
changes outside. All inherited pictographs remain. Pepe's heavy-lidded eyes,
wide mouth and five digits on each hand are untouched; no new hands were added.
The final full wall and 512 × 512 JPEG were inspected. No text or prohibited
symbols were observed. The motif is faint in the thumbnail, and the intended
tiny chalk pebble is indistinct. REVIEW-29.json records these limitations and
the explicit required JPEG location exception.

Only the final wall and required thumbnail remain from image generation. The
